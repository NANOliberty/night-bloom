# 키프레임 프롬프트

도구: ChatGPT(단순 구도·소품), Gemini Nano Banana(복합 포즈·상호작용). 한 컷당 2~4회 생성 후 1장 채택.

## 일관성 규칙

1. 컷에 나오는 대상의 **시트를 전부 첨부** (아이·로봇·외계인·우주선). 배경이 보이면 `bg_hill_master.png`도.
2. 같은 장소의 컷은 **앞 컷 결과를 레퍼런스로 다시 첨부** (예: 나무 아래 컷은 kf_08, 누운 로봇 컷은 kf_25).
3. 소품이 매번 달라지면 **그 소품만 크롭한 레퍼런스**를 만들어 붙인다 (`ref_engine.png`).
4. 구도는 맞고 한 요소만 틀리면 전체 재생성 대신 **부분 수정**: "첨부한 장면을 그대로 유지하고 X만 수정해줘".
5. 상태가 바뀌는 컷은 **앞 컷 상태를 명시** ("첨부한 12번처럼 빛이 꺼진 상태").

## 공통 머리 (모든 컷 프롬프트 앞)


## 시트 프롬프트 (요약)

- **배경** — 밤, 언덕 위 외딴 돌집과 양철 지붕, 꼭대기 큰 나무 한 그루, 멀리 마을 불빛. 남색 하늘에 별만, 은하수 없음. 굵은 외곽선 2단계 셀셰이딩.
- **아이** — 7살, 적갈색 단발, 파란 눈, 흰 티+파란 데님 멜빵반바지(밑단 접음)+흰 양말+빨간 하이탑, 이마에 검은 띠 헤드랜턴. 정면·측면·뒷모습.
- **로봇** — 낡은 상자형 모니터 머리(화면에 청록 눈 램프 2개, 안테나 2개) + 소형 세탁기 몸통(가슴에 둥근 문) + 주름 호스 팔 + 바퀴. 아이 가슴 높이. ("CRT television"은 GPT가 저작권으로 거부 → "boxy old monitor casing"으로 우회)
- **외계인** — 아이 무릎~허리 높이, 거친 회색 운석 돌덩이, 금 간 틈으로 연보라 빛, 큰 틈 안 빛 점 두 개가 눈, 입·더듬이 없음, 뭉툭한 돌 팔다리.
- **우주선** — 매달린 등불형. 녹슨 금속 고리와 테두리, 종 모양 젖빛 유리 선체에 선·점 문양, 안에서 연보라 빛, 바닥 중앙에 원통 엔진 유닛. 아이 키보다 조금 큼.
