# 스토리라인

## 로그라인

뒷마당에서 고물 로봇과 사는 아이 앞에 작은 우주선이 떨어진다. 셋이 우주선을 고치는 동안 친해지지만, 정작 멈추는 건 로봇이고 외계인은 자기 우주선의 엔진을 빼서 로봇에게 끼워 준다.

주제 한 줄: 고치던 쪽이 고쳐지는 쪽이 된다 — 도움은 방향이 없다.

## 구성 (곡 Night Bloom 2:52 기준)

| 구간 | 시간 | 내용 | 핵심 컷 |
|---|---|---|---|
| 인트로 | 0:00~0:15 | 뒷마당 일상. 아이와 로봇의 하이파이브(탑뷰, 두 손). 둘이 올려다보는 하늘로 유성이 떨어진다 | 하늘 ① |
| 1절 | 0:15~0:45 | 달려감. 나무에 걸린 우주선 발견. 젖빛 선체 안에서 작은 실루엣이 움직인다. 아이가 물러선다 | |
| 후렴 1 | 0:45~1:10 | 로봇 눈이 우주선 빛과 같은 색으로 깜빡임 → 우주선 빛이 꺼지고 음악 브레이크 → 0:55 드럼과 함께 해치가 열리며 외계인이 떨어진다 | 외계인 등장 |
| 2절 | 1:10~1:40 | 우주선을 내려 엔진을 꺼내고(구도 A), 새벽·낮·저녁에 걸쳐 고친다 | 거울 구도 A |
| 후렴 2 | 1:40~2:05 | 1:40 급락과 함께 로봇이 멈추고 쓰러진다. 배터리를 빼 봐도 반응이 없다 | 눈 꺼짐 |
| 브릿지 | 2:05~2:22 | 외계인이 혼자 하늘을 본다. 엔진을 집어 들고, 꺼진 자기 우주선을 한 번 올려다본 뒤 로봇에게 걸어가 끼운다(구도 B) | 거울 구도 B |
| 엔딩 | 2:22~2:52 | 로봇 눈이 연보라로 켜진다. 아이가 끌어안고 외계인이 기댄다. 셋이 빈 우주선을 나무에 다시 매단다. 세 손 포개짐, 셋이 보는 하늘, 첫 장면과 같은 언덕 전경 | 하늘 ③ |

## 연출 장치

- **빛의 이동** — 우주선 → 엔진 → 로봇으로 연보라 빛이 옮겨 간다. 화면 광원도 같이 옮긴다.
- **거울 구도** — 19번(로봇이 우주선 엔진을 꺼냄)과 31번(외계인이 로봇에 엔진을 넣음)을 같은 카메라·같은 손 위치로.
- **로봇 눈 = 유일한 대사** — 등장 때 우주선 빛과 동조(11) → 고장 때 꺼짐(24) → 엔딩 때 연보라로 켜짐(32).
- **세 번의 하늘** — 둘이 보는 하늘(4) → 외계인 혼자 보는 하늘(27) → 셋이 보는 하늘(34). 같은 구도.
- **손 포개짐** — 인트로 2손(3) → 엔딩 3손(33). 탑뷰 미디엄샷.
- **수미상관** — 1번과 35번은 같은 언덕 전경. 35번에만 등불(우주선)·빛 세 점·창문 불이 더해진다.
- **등불** — 우주선은 등불 모양. 엔진을 뺀 뒤 바닥에 놓였다가 엔딩에서 셋이 나무에 다시 매단다. "떠날 수단"이 "머무는 자리의 등불"이 된다.

## 복선

- 로봇 세탁기 문 안에 엔진과 같은 규격의 원통형 배터리가 있다. 25번에서 아이가 그 배터리를 빼 봐도 반응이 없고, 31번에서 외계인이 죽은 배터리 자리에 엔진을 끼운다.
- 2번의 아이는 드라이버로 로봇을 정비한다. "만들고 고치는 아이"를 먼저 보여 줘야 21번에서 외계인의 엔진을 고치는 게 자연스럽다.

## 디자인

기준: 생성 AI가 컷마다 흔들려도 같은 대상으로 보이도록 실루엣을 서로 다르게 하고, 각자 고정 식별 요소를 하나씩 둔다. 색은 아이=흰 빛, 로봇=청록, 외계인·우주선·엔진=연보라. 배경은 남색·짙은 초록으로 눌러 세 빛만 튀게.

| 대상 | 디자인 | 고정 식별 요소 |
|---|---|---|
| 배경 | 언덕 위 외딴 집(돌벽+양철 지붕), 풀밭, 꼭대기 큰 나무 한 그루, 멀리 마을 불빛 | 언덕 꼭대기 나무 |
| 아이 | 7살, 적갈색 단발, 흰 티+파란 멜빵반바지+빨간 하이탑, 이마에 헤드랜턴 | 헤드랜턴(흰 빛) |
| 로봇 | 브라운관 TV 머리(눈 램프 2개) + 소형 세탁기 몸통(둥근 문) + 호스 팔 + 바퀴 | TV 화면 눈(청록 → 연보라) |
| 외계인 | 거친 회색 운석 돌덩이, 금 간 틈으로 연보라 빛, 틈 안 빛 점 두 개가 눈. 감정 = 틈 열림 정도 + 빛 세기 | 틈 사이 연보라 빛 |
| 우주선 | 매달린 등불형. 녹슨 고리와 테두리, 종 모양 젖빛 유리 선체. 바닥 중앙에 원통 엔진 유닛 | 선체 전체의 연보라 발광 |
| 엔진 | 음료 캔 크기 원통, 회색 몸통에 양 끝 황동 띠, 한쪽 끝 연보라 렌즈 | 연보라 빛 |

시트는 `sheets/`에 5장 + 엔진 레퍼런스(`ref_engine.png`, 19번 키프레임에서 잘라냄).

## 지브리식 전개 체크리스트 (스토리보드 끝내고 돌린 것)

- 악역·큰 갈등 없음. 장애물은 시간과 고장뿐
- 일상 행동 컷이 절반 이상 (정비, 걷기, 올려다보기, 앉아 있기)
- 비일상은 하나만(외계인), 설명 없이 등장
- 인물 없이 풍경만 머무는 샷 (1, 35)
- 감정은 표정보다 행동으로 (물러섬, 고개 숙임, 끌어안음)
- 새벽·낮·저녁으로 시간 경과 (20·21·22)
- 결말은 해결이 아니라 "조금 달라진 채로 계속됨" — 첫 구도를 엔딩에 반복
- 카메라는 고정 또는 느린 줌. 한 컷에 움직이는 건 한 가지
